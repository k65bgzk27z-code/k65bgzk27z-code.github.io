プライバシーポリシー

このページは、個人用「読書ノート」によるGoogleユーザーデータの取り扱いを説明します。

アクセスする情報と目的

Gmailの読み取り専用権限（gmail.readonly）を使用します。指定の転送前アドレスとKindle・Amazon関連語を含むメールを検索し、件名、送受信ヘッダー、本文、商品リンクを読み取り、購入した本の情報と送信元認証を確認します。検索に一致した購入以外のメールも、判定に必要な範囲で読み取る場合があります。

保存

本の記録、メールID、判定結果、確認待ちのための本文抜粋はMac内のSQLiteに保存します。OAuth認証情報はmacOSキーチェーンへ保存し、保存できない場合はMacの本人のみが読めるdata/private内の専用ファイルへ保存します。認証情報をソースコードや実行ログに書き込みません。

共有と同期

本の記録は、利用者が設定した場合にObsidianの保管庫へ書き出され、iCloudを通じて利用者の端末へ同期されます。メール本文と認証情報はObsidianの本ノートへ書き出しません。Googleユーザーデータを広告目的で販売・共有したり、Sitesや有料AIへ送信したりしません。

公開説明ページ

説明ページだけをGitHub Pagesで公開しています。この公開先には本棚、メール、OAuth認証情報をアップロードしません。GitHubは安全対策のためアクセス元IPアドレス等を記録します。詳しくはGitHubのプライバシーステートメントをご覧ください。

停止・削除

アプリの「このMacの接続を解除」で保存したOAuthトークンを削除し、毎時のGmail取り込みを停止できます。Googleアカウントの接続済みアプリからアクセスを取り消すこともできます。本棚の本はアプリ内で削除でき、ローカルの保存データとバックアップは利用者が管理します。アプリの接続解除だけでは本棚やバックアップは削除しません。

Google APIから受け取った情報の利用は、限定的な使用の要件を含むGoogle API Services User Data Policyに従います。
